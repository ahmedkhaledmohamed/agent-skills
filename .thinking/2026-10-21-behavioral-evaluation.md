# Portable workflow evaluation and maintenance

## Problem Framing

The collection contained reusable workflow guidance without dedicated behavioral acceptance cases or a complete runtime/dependency selection inventory. Lessons needed a clear home so task facts and personal policy would not accumulate as universal skill rules.

## Approach

Added fictional cases, a recorded-observation evaluator, synthetic evaluator tests and a complete dependency catalog. Documented reviewed lesson placement and made narrow scope and approval-checkpoint improvements to existing skills.

## Key Decisions

Separated mechanical action checks from reviewer-normalized semantic assessment and left missing evidence unverified. Default validation invokes no model; synthetic evaluator tests are not presented as successful agent runs.

## Outcome

Case definitions, catalog coverage, evaluator tests, portability checks and the specification example passed locally. The contribution extractor found no matching sessions, so this record summarizes the visible task without retaining conversations.
