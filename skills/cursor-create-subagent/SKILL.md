# cursor create subagent
Read current Cursor subagent documentation and existing .cursor/agents or ~/.cursor/agents entries before editing.
Set the role, activation boundary, permitted responsibilities, and output contract. Use only model identifiers and configuration fields supported by the installed runtime.
Do not automatically delegate unrelated work. For Codex subagents, use current Codex guidance; Cursor markdown agent files are not interchangeable with Codex configuration.
