# Report eval results
Use the installed eval-reporter skill when available, preserving the requested time window and output form.
Otherwise locate the eval framework checkout and inspect core.reporter for supported functions. Read existing results and report actual counts, methods, coverage, and limitations.
Keep structural, judge, explicit human, and heuristic workflow signals distinct. Compare compatible rubric/model versions and do not fill missing records with zero scores.
Only create or persist additional artifacts when requested. Do not claim a dashboard or report was saved unless verified.
