# Search a knowledge base
Resolve the corpus, access method, and applicable guidance. Discover the actual search tool or CLI and supported filters rather than assuming paths or commands.
For a local CLI, use its documented working directory and interpreter. Start with relevant terms, then expand synonyms or date scope as needed.
Inspect original documents and dates before citing. Retrieval scores rank relevance; they do not measure truth, authority, or certainty.
Corroborate ownership and current status with authoritative current sources. Distinguish historical corpus information from live state.
If no result is found, try alternate terms and state corpus/access limits. Missing results are not proof of absence.
Keep searches read-only. Do not rebuild indexes, synchronize documents, or start authentication as an automatic fallback.
