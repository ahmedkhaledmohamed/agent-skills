# cursor onboard
Use the user's known preferences and task context instead of repeating setup questions.
Identify a useful first task and the relevant Cursor capability. Explain unavailable integrations honestly; do not call cursor_dialog or other tools unless exposed.
Do not persist personal preferences or configure accounts without the user's requested scope.
For Codex onboarding, use current Codex guidance and tools instead of Cursor-only memory or editor APIs.
