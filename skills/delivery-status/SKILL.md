# Summarize team delivery
Resolve the team, cycle, and scope. Fetch current upstream repository status records before relying on them.
Prefer authorized planning and issue-tracking sources for current delivery. Discover tool schemas and verify the intended account before authorization or writes.
Use local knowledge-base tools only after confirming their read-only access path and credentials boundary.
Separate tracking status, ongoing operational contributions, deliverable completion, rollout, and measured impact. Unknown cancellation reasons remain unknown.
State freshness and coverage. If live access is missing, provide a clearly dated historical view without implying it is current.
A status question does not authorize saving status files, changing trackers, synchronizing the corpus, or messaging the team.
