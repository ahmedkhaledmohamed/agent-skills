# cursor env setup
Discover available environment inspection/configuration tools and the intended repository/environment. Inspect existing configuration without changing it.
Fetch current official Cursor Cloud Agent environment guidance for the chosen operation. Resolve supporting references from the actual installation rather than assuming bundled files exist.
Distinguish repository-managed configuration from service-managed configuration using actual tool responses, not assumptions.
Prepare the concrete configuration and validation for the user's requested change. Apply existing authorization before creating environments, running installation/startup commands, or changing remote settings.
If required tools or documentation are inaccessible, report the missing capability and provide only the supported local portion. Do not fabricate successful cloud validation.
Use Codex documentation for Codex environments instead.
