# cursor canvas
Use only in a runtime that supports Cursor Canvas. A table or structured answer alone is not a reason to change the requested output surface.
Read the installed cursor/canvas type declarations and current Cursor guidance before writing. Resolve the actual workspace canvas directory; do not invent its path or assume write permission.
Use supported imports, data handling, and diagnostics. Validate the actual rendered artifact when available.
